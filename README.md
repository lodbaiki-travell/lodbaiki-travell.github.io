# По Оке на лодке

Сайт о лодочных походах, путешествиях по реке Ока, туристических маршрутах и снаряжении.

## Локальный запуск

Откройте `index.html` в браузере или запустите HTTP-сервер из корня репозитория.

```sh
python3 -m http.server 8080
```

Затем откройте [localhost:8080](http://localhost:8080/).

## GitHub Pages

После слияния Pull Request выберите **Settings → Pages → Deploy from a branch**, затем ветку `main` и папку `/ (root)`. Сайт использует относительные пути и готов к размещению по адресу проекта. [Ожидаемый адрес сайта](https://zhirnovdp-crypto.github.io/oka-boat-travel/)

## Материалы

- Маршруты предварительные. В разделе «Наши походы» приведён пример программы ночёвки, который можно заменить первым отчётом о выезде.
- Изображения в `assets/images/` созданы с помощью ИИ по мотивам пейзажей Оки.
